GTM Agent Together AI · 2026
Python LLM-as-Judge Synthetic Eval Sets McNemar Test Bootstrap CI Best-of-N Error Analysis Grounding

Built the evaluation system behind Together AI's Salesforce-embedded answer engine. An adversarial harness auto-generates questions across the eight live data lanes, runs the live agent, and grades every answer with an LLM judge. Error analysis sorts each failure into categories (hallucination, coverage gap, non-responsive, wrong-entity), and a deterministic verifier flags fabricated numbers, record IDs, and company names; a best-of-N selector then picks the least-fabricated answer, which lifted accuracy 7.5 percentage points. Rebuilding the inference path cut compound-query latency from 165 seconds to 6.3. Internal systems; happy to walk through the methodology live.

Evals ran

Model and prompt changes ship only if they clear a paired McNemar test on a frozen 133-question set, with 95% bootstrap confidence intervals and a p<0.05 gate, so a reported gain is signal and not judge or sampling noise. The LLM judge is cross-checked by a second model from a different family to control for self-preference bias.
